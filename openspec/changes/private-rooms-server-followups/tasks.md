# Tasks

The Backend tasks are done in `../server` by the backend team, on its own branch; nothing of them is committed from this repository. Each states the behaviour asked and how it is accepted; the reading behind it is kept outside the repository. A Client task starts only after the Backend task it names has merged and been read through CodeGraph; one task is then one commit with its tick (the "Commits" paragraph of `openspec/config.yaml`).

A leave, a removal and a role change of a member who already has access, and an owner change by an owner without keys, shall go through whatever the keys of that member or owner. - [ ] 1.3 Backend: make the per-file key listing follow the room: it shall hold the room owner and every user who has access to the file, and no user who no longer has access to the room, the file's creator included. Verify: server tests for a file uploaded by a member, whose listing holds the owner's keys, and for a file whose creator left, whose listing does not hold the creator's
- [ ] 1.4 Backend: when the rooms of a deleted user are reassigned, no private room shall end with an owner who cannot open its files. Verify: a server test reassigns a private room to a user without keys and states the outcome, which leaves no private room owned by that user
