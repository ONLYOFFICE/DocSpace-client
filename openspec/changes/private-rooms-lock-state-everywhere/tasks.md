# Tasks

One task is one commit with its tick (the "Commits" paragraph of `openspec/config.yaml`). No locale changes: the change adds no text. Keep the pre-push gate in mind: tsc, biome, locale tests, shared, client, sdk and doceditor unit tests must stay green. Groups 1 and 2 can be released without the later groups. Unit commands: shared `cd packages/shared && pnpm exec vitest run <path>`, client `cd packages/client && pnpm exec vitest run <path>`, sdk `cd packages/sdk && pnpm exec vitest run <path>`, doceditor `cd packages/doceditor && pnpm exec vitest run <path>`. A change under `packages/shared` is type-checked with `pnpm exec tsc` in shared, client, sdk, doceditor, login and management.
